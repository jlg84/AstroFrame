# AstroFrame 0.2.0

First native PySide6 build.

## Features

- Opens local reference images
- Smooth mouse-wheel zoom
- Click-and-drag panning
- Accurate overlays for both current rigs
- Show either or both rigs at the same time
- Shared rotation control
- Centre overlays button

## Install

From the AstroFrame repository folder:

```bash
python3 -m pip install -r requirements.txt
```

## Run

```bash
python3 main.py
```

## Copy into the repository

Copy these items into the root of the cloned AstroFrame repository:

- `main.py`
- `astroframe/`
- `requirements.txt`
- `README_0.2.0.md`

Then run the application before committing.
