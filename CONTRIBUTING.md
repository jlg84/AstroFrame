# Contributing

AstroFrame is currently in active 1.0 release-candidate development. Feedback and testing are especially useful around the core reference-image-to-capture workflow.

## Feedback priorities

Please report issues that affect:

- loading and plate-solving a reference image
- target identification and catalogue-object placement
- comparing equipment fields of view
- positioning, rotating or mosaicking the frame
- observing-site and observability calculations
- Equipment Advisor recommendations
- exporting useful framing information for NINA or ASIAIR

## When reporting a problem

Please include, where relevant:

- AstroFrame version/build (for example `1.0-RC22x`)
- operating system and version
- reference-image filename, format and dimensions
- selected equipment profile
- selected observing site
- what you expected to happen
- what actually happened
- a screenshot and/or relevant Solver Log output

AstroFrame is currently packaged and tested on macOS, with Windows packaging and testing planned as part of the 1.0 release work. Reports that help identify platform assumptions in the Python/Qt application are welcome.
