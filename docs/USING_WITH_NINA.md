# Using AstroFrame with NINA

The current AstroFrame build provides a manual handoff.

1. Load and frame the reference image in AstroFrame.
2. Enter the target centre RA and Dec.
3. Adjust the camera rotation.
4. Click **Copy NINA values**.
5. In NINA, open **Framing**.
6. Enter the RA and Dec directly in the Framing coordinate fields.
7. Set the field of view and rotation.
8. Load the survey image and send the target to the sequencer.

NINA Sky Atlas is primarily a catalogue search tool and does not provide a simple coordinate “Go” control. Direct coordinates belong in the Framing tab.
