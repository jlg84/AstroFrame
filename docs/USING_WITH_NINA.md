# Using AstroFrame with N.I.N.A.

1. Load and plate-solve a reference image in AstroFrame.
2. In Equipment Advisor, choose a rig and (when offered) a **Shoot this instead** framing.
3. Adjust the rig rotation if desired.
4. In **Export → N.I.N.A. handoff**, use **Copy RA**, **Copy Dec**, and **Copy rotation** for the three corresponding fields in N.I.N.A. Framing Assistant.
5. **Copy all** places a labelled summary on the clipboard for notes or reference.

AstroFrame expresses RA as sexagesimal hours, Dec as signed sexagesimal degrees, and the camera rotation as a position angle in degrees.
