# AstroFrame 1.0 RC1 — private tester guide

Thank you for testing AstroFrame before its wider release. This is a release candidate: the core application is considered feature-complete for 1.0, but the project is deliberately testing installation and first-use behaviour on computers that have never hosted AstroFrame before.

## What AstroFrame is for

Load a reference astrophotograph and AstroFrame helps answer a practical question: **can I reproduce this framing with my own equipment, and what framing should I send to NINA or ASIAIR?**

## Please try these things

- Install and launch AstroFrame without development tools or Terminal-based setup.
- Add your real observing site and at least one imaging rig.
- Load several JPEG, PNG or TIFF reference images.
- Let AstroFrame identify or plate-solve them.
- Compare the displayed field with your own equipment.
- Try reframing and rotation.
- Try a mosaic on an image that is too large for one of your rigs.
- Import a target collection if you have one.
- Try an object layer and clickable object markers.
- Export framing information to NINA or ASIAIR if you use either workflow.

## Particularly useful feedback

Please report anything that is confusing even if it is technically working. First-run assumptions, unclear labels, hidden controls, installation/security friction and unexpected defaults are especially valuable at this stage.

For a problem, please include:

- what you were trying to do;
- what you expected;
- what happened instead;
- your Mac model and macOS version;
- the reference image or catalogue involved, when relevant;
- a screenshot if it helps explain the problem.

## RC1 boundaries

This is not the moment for feature requests to block the release unless the missing behaviour prevents normal use. New ideas are welcome, but RC1 is primarily about finding bugs, installation failures and first-use friction.
